# Chiikawa & Friends ♡

**Alumno:** Ana Maritza Arellano Ortiz

**Descripción:** Aplicación web de una sola página para administrar una colección de personajes inspirada en Chiikawa.

**Enlace a GitHub Pages:** https://minmin-zay.github.io/Chiikawa-CRUD-Personajes/

## Funciones
- Ver personajes en tarjetas responsivas y consultar sus detalles.
- Agregar, editar y eliminar con confirmación.
- Buscar por nombre o rol en tiempo real (sin distinguir acentos ni mayúsculas).
- Marcar personajes con el botón de corazón y consultarlos en la pestaña **Mis favoritos**. Los favoritos se guardan en `localStorage`.
- Validar nombre, rol, duplicados e imágenes PNG/JPG.
- Conservar cambios en `localStorage`, incluso tras recargar.
- Mostrar estados vacíos, errores de imágenes y recuperación ante JSON inválido.

## Uso
Abre `index.html` en el navegador. Para añadir un personaje, selecciona **Agregar amigo** y llena los campos. Para editar o eliminar, primero entra a **Ver detalles**. Haz clic en **♡** en una tarjeta o en los detalles para añadir o quitar un favorito; abre **♥ Mis favoritos** para ver solo los marcados. Puedes guardar rutas como `./imagenes/chiikawa.png` o URLs que terminen en `.png`, `.jpg` o `.jpeg`.


## Recursos
- HTML5, CSS, JavaScript, [Bulma](https://bulma.io/) y [Google Fonts — Fredoka](https://fonts.google.com/specimen/Fredoka).
- Ilustraciones PNG sencillas creadas para esta práctica. Los personajes Chiikawa son creación de Nagano.
